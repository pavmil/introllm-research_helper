# Задачи

Каждая задача — отдельный файл `NNNN-slug.md` по [шаблону](_TEMPLATE.md). Агент начинает работу **только** с файла задачи, в котором заполнены:
- контекст;
- scope;
- контракты;
- критерии приёмки;
- стоп-условия.

Агент выполняет заранее расписанную задачу заметно лучше, чем устную просьбу. Шаблон заставляет заранее решить то, о чём иначе агент будет гадать.

## Правила

- **Статусы:** `todo` → `in-progress` → `done` (или `blocked` / `dropped` с причиной в журнале).
- **Журнал выполнения** ведёт исполнитель: что сделано, что не получилось, какие гипотезы. Если сработало правило трёх попыток, это тоже записывается в журнал.
- **Большая задача** (больше дня или больше ~400 строк diff) делится на несколько.
- **Решения, принятые по ходу**, — в ADR и `docs/HISTORY.md`, ссылка из итога задачи.
- **Задачи для людих** (разметка, golden set, ключи) можно не оформлять отдельными файлами, если они уже расписаны в плане недели.
