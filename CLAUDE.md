# CLAUDE.md — конфигурация для Claude Code

Общие правила для всех агентов — в AGENTS.md, он подключается ниже целиком. Здесь только то, что специфично для Claude Code.

@AGENTS.md

## Специфика Claude Code

- **Хуки.** `.claude/settings.json` подключает `.claude/hooks/loop_guard.py`:
  - перед Bash/Edit/Write;
  - после Bash.
  Если хук заблокировал вызов (сообщение начинается с `loop-guard:`), это сигнал остановиться по AGENTS.md §6, а не ошибка, которую нужно обойти. Запиши ситуацию в журнал задачи и смени подход или спроси человека.
- **Разрешения.**
  - Без подтверждения: `make …`, `uv run …`, `uv sync`, `git status/diff/log`.
  - С подтверждением: `git push`.
  - Запрещено: чтение `.env`.
  - Личные переопределения — в `.claude/settings.local.json` (в .gitignore).
- **План.** Для многошаговой работы веди список шагов, совпадающий с разделом «План» файла задачи, и отмечай прогресс по мере выполнения.
- **Язык.**
  - Общение и документация — на русском.
  - Код, идентификаторы, docstring, сообщения коммитов — на английском (Conventional Commits, см. CONTRIBUTING §6).
- **Память.** Решения, которые должны пережить сессию, записывай в `docs/HISTORY.md` или ADR, а не только в память агента: репозиторий — общий источник правды для всех агентов и людей.
- **Субагенты.** Для широкого поиска по коду можно использовать субагентов. Правки, затрагивающие контракты, делает основной агент.
