# experiments/

Результаты прогонов. Один прогон — одна папка `YYYY-MM-DD_<name>/`:

```
2026-10-24_week1_smoke/
├── config.yaml     # системы, модели и их версии, бюджеты, seed, git commit
├── results.json    # машиночитаемые метрики (из них строятся таблицы и графики)
├── labels.csv      # ручная разметка, если была
├── notes.md        # что запускали, что увидели, что не так
└── raw/            # сырые ответы, логи, трассы — в .gitignore
```

## Правила

- **Без `config.yaml` прогон не считается** — его нельзя воспроизвести.
- В `config.yaml` обязательно:
  - коммит git;
  - ID моделей и дата запуска;
  - версии baseline-пакетов;
  - профиль бюджета.
- Сырые данные (`raw/`, `cache/`) в git не попадают. Если они нужны для воспроизводимости — хеш и место хранения в `notes.md`.
- Результаты не перезаписываются: новый прогон — новая папка.
