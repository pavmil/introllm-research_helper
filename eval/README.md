# eval/

Данные для оценки, а не код. Код метрик, судьи и статистики — в `src/research_helper/evaluation/`.

| Путь | Что |
|---|---|
| `golden/_template.yaml` | Шаблон вопроса FreshSci |
| `golden/freshsci_dev.yaml` | 10 dev-вопросов: на них можно тюнить промпты, пороги и бюджеты |
| `golden/freshsci_test.yaml` | 20–30 test-вопросов. **Не используются для тюнинга.** Создаются позже |
| `labels/` | Ручная разметка утверждений (формат — [docs/labeling-guide.md](../docs/labeling-guide.md)) |

## Правила

1. **Ключевые пункты вопроса пишутся до запуска любой системы на нём** — иначе golden set подстраивается под ответы систем.
2. Test-вопросы не открываются агентами при разработке промптов и порогов.
3. Каждое изменение golden set после первого прогона — отдельный коммит с причиной в сообщении.
4. Скачанные бенчмарки (SciFact, LitSearch, QASPER…) в git не хранятся: только скрипты загрузки и хеши.
