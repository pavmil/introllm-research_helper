# prompts/

Промпты — версионированные файлы, а не строки в коде.

## Правила

- **Имя файла:** `<роль>.v<N>.md`, например `b0_closed_book.v1.md`, `asker.v2.md`.
- **Выпущенную версию не редактируем.** Использовалась в эксперименте → изменение = новый файл `v<N+1>`. Иначе результаты прогонов нельзя сопоставить с промптом.
- В трассе каждого LLM-вызова пишется имя и версия промпта.
- **В начале файла — короткая шапка:** назначение, ожидаемый формат вывода (ссылка на Pydantic-схему), что изменилось относительно предыдущей версии.
- Текст статей и ответы внешних API подставляются в промпт **внутри явных разделителей** с пометкой, что это данные, а не инструкции (защита от prompt injection, design-doc §9.1).
- **Few-shot примеры** берутся только из dev-частей и train-частей, никогда из test.
