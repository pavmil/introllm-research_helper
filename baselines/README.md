| B2 | B1 + reranker + verifier + аудит | `baselines/b2_rag_verify/` | недели 5–6 |

| B4 | Наша система | `src/research_helper/` | недели 3–9 |
| B5 | PaperQA2 (`paper-qa`) | `baselines/paperqa/` | неделя 1, вручную |

## Отдельные окружения

`knowledge-storm` и `paper-qa` тянут собственные версии зависимостей (dspy, litellm и др.). Поэтому:
- в основное окружение их **не ставим**;
- у каждой системы своё окружение внутри её папки (`uv venv` + `uv pip install` с зафиксированной версией);
- версия и способ установки описываются в README папки.

Общее с основным пакетом — только форматы входа и выхода: вопросы из `eval/golden/`, результаты в `experiments/`.
